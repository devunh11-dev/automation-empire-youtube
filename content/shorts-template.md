# Reusable 27-Second Short Template

**Topic:** [one practical problem]
**Audience:** [who has this problem]
**Proof/demo:** [what you can actually show]
**CTA:** [one next action]

## Script skeleton
- **0–2s — Hook:** “Stop [common friction] — here's a simpler way.”
- **2–7s — Context:** “If you're [audience], you probably [problem].”
- **7–18s — Demo:** “I use [tool/action] to [specific step]. Watch: [show actual screen].”
- **18–23s — Takeaway:** “The useful part is [one clear lesson/limitation].”
- **23–27s — CTA:** “Follow for [next specific series].”

## Production requirements
- Write for the creator's own face and real voice.
- Target 48–62 spoken words, then time an actual read-through.
- Include one visual proof point that can be shown on screen.
- Never claim a tool works unless it has been tested.
- Add a short caption, title, description and 5–8 relevant tags.
- Do not copy another creator's exact script, sequence, branding or footage.
