# Automation Empire — YouTube Autopilot

A free-first, approval-gated content workflow for the Devun H YouTube channel.

## Guardrails
- Exclude HeyGen and vidIQ.
- $0 budget: no paid plans, credits, API tiers, purchases, or paid services.
- Preserve existing projects, assets, and records. Do not delete or overwrite existing content.
- Never publish, schedule, or distribute publicly until the weekly batch has been explicitly approved.
- Research competitors for high-level patterns only. Scripts, demonstrations, thumbnails, narration, and edits must be original.
- Do not report a render, upload, schedule, or publication as successful without provider confirmation.

## Workflow
1. Research current audience questions, credible sources, and public competitor patterns with Exa.
2. Produce an original brief: target viewer, problem, unique angle, promise, proof/demo, sources, and CTA.
3. Draft one long-form script and up to three distinct Shorts scripts, plus titles, descriptions, tags, chapters, and pinned-comment copy.
4. Produce from creator-owned footage, screen recordings, and original graphics using verified free tools only. Do not assume a free renderer is available.
5. Reuse existing Canva brand assets; create a thumbnail and vertical cover variants only if needed.
6. Quality-check facts, originality, rights, spelling, audio, captions, aspect ratio, resolution, and final-file playback.
7. Prepare a weekly approval pack containing exact asset links, metadata, destination accounts, proposed release times/timezone, disclosure decisions, QA results, and unresolved blockers.
8. After approval, upload via the active YouTube connection. Keep the upload private until its metadata and scheduled release are confirmed through a supported official route.
9. Repurpose into distinct Shorts and platform-specific posts. Schedule only to verified supported Metricool networks/accounts after approval.
10. Record confirmed performance in the existing tracker: impressions, views, CTR, average view duration, retention, subscribers, comments, and production time. Missing values remain unknown, not zero.

## Initial operating target
- One long-form tutorial or experiment per week.
- Up to three Shorts from original footage or separately scripted demos.
- One weekly approval pack. Reduce output if free production tools cannot meet quality requirements.

## Approval gate
No approval means no upload, schedule, public release, or promotional post. The approval request must show the exact final video, thumbnail, title, description, tags, playlist, audience setting, visibility, destination account, proposed date/time/timezone, AI disclosure choice, and QA results.

## Technical limits
- An active OAuth connection is not proof that a finished video file exists or that upload permissions are fully tested.
- The discovered multipart YouTube upload path requires an actual staged file object; never invent a storage key or upload placeholder media.
- Supabase remains inactive and must not be reactivated or migrated as part of this free build.
- Weekly preparation is separate from provider upload/scheduling. Do not claim continuous background publishing unless a verified automation and end-to-end provider run exist.
